# Perfect Pour

A dependency-free wine-pouring game inspired by Moldovan pottery, decorated crystal glasses, and geometric folk ornament.

The natural hand and pouring-jug artwork is stored locally in `assets/`; the fillable vessels remain native Canvas drawings.

## Run locally

```bash
python3 -m http.server 8080
```

Open <http://localhost:8080>.

No packages, installation, or build step are required.

## How to play

- Select **Start pouring**.
- Hold the mouse button, touch the screen, or hold **Space** to pour.
- Release when the wine reaches the mark on the glass or clay cup.
- Select **Următorul vas** to continue.
- Press **Escape** or use the reset button to empty the current vessel.
